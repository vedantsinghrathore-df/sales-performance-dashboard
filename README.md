# Sales Performance Dashboard

## Overview

An Excel-based sales performance dashboard designed to transform raw sales data into clear business insights.

## Features

- Data cleaning and preparation
- Revenue and profit analysis
- Order and sales KPIs
- Product performance analysis
- Regional performance analysis
- Interactive dashboard
- Business insights and recommendations

## Key Metrics

- Total Sales: ₹34.25M
- Total Profit: ₹8.26M
- Total Orders: 800
- Profit Margin: 24.1%
- Average Order Value: ₹42,813

## Tools Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Design
